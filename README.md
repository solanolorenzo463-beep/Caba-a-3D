# Cabaña 7 × 5 m + 2 m de balcón — Modelo 3D

Visor 3D interactivo (three.js). Abrir `index.html` en el navegador.

- Arrastrar: girar · Rueda: zoom · Clic derecho: mover
- Botones: ocultar techo, vista en planta, ocultar entorno
- Descarga del modelo: OBJ + MTL o GLB (SketchUp 2025+ importa GLB)

## Publicar con GitHub Pages
Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save.
